# SmartCity Alert - Global Solution Java 2026

## Sobre o Projeto

O **SmartCity Alert** e uma aplicacao Java para simular o monitoramento de ocorrencias urbanas em uma cidade inteligente.

## Objetivo

Criar uma solucao simples, funcional e organizada para registrar, listar, resolver e acompanhar ocorrencias relacionadas a infraestrutura urbana.

## Estrutura Inicial

```txt
src/
|-- app/
|   `-- Main.java
`-- util/
    `-- Menu.java
```

## Fluxo Planejado

```txt
1 - Registrar ocorrencia
2 - Listar ocorrencias
3 - Resolver ocorrencia
4 - Gerar relatorio
5 - Sair
```

## Como Executar

```bash
cd src
javac app/Main.java
java app.Main
```
